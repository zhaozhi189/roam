## 实现摘要(2026-06-12)

| 功能 | 实现 | 关键点 |
|---|---|---|
| F-11 GIF | ⑦ 卡「🎞 录 GIF(3s)」:抓 24 帧(360px / 8fps)→ 纯 JS GIF89a 编码(median-cut 256 色 + LZW)→ saveVideoBase64 落盘 + 相册 | **零 vendor 依赖**;编码器已用独立 LZW 解码器离线交叉验证(24 帧 roundtrip + sips 可解) |
| F-09 运镜 | ④ 卡运镜区:📍记点(存 currentCam 位姿)→ ▶ 预览(Catmull-Rom 插值,每段 3s)→ 🎬 录运镜(自动串联现有录屏) | 播放只写 cam 字段,定位仍走 updateCameraEachFrame,**相机代码零改动**;切场景自动清空路径 |
| Native | mimeFromFilename + listRecordings + exportToMediaStore 三处加 `.gif` | RoamLogicTest 47 个全绿(新增 mime_gif) |

## F-11 · GIF 导出验证

- [ ] **M9-11a** 场景就绪后 ⑦ 卡「🎞 录 GIF(3s)」按钮可点(未启动场景时 disabled)
- [ ] **M9-11b** 点击 → badge 依次显示「抓帧 n/24」→「编码中…」→「✓ roam-xxx.gif (NNNKB)」
- [ ] **M9-11c** ④ 列表刷新后出现 .gif 项,**缩略图是会动的**(列表里直接播放)
- [ ] **M9-11d** 文件大小 ≤ 1MB(微信表情包上限;360px/24帧 预估 300-800KB)
- [ ] **M9-11e** 「分享」→ 微信 → 接收方收到会动的 GIF(长按可收藏为表情)
- [ ] **M9-11f** 系统相册看到 GIF(Pictures/Roam/)
- [ ] **M9-11g** AR-lite 模式下录 GIF → 带相机真景背景(非黑底)
- [ ] **M9-11h** GIF 右下角有「Roam · 即境」水印
- [ ] **M9-11i** adb 桥:`adb shell am broadcast -a com.roam.app.AUTO --es cmd gif`

## F-09 · 运镜路径验证

- [ ] **M9-9a** 场景就绪后 ④ 卡运镜区「📍 记点」可点,计数「· 0 点」
- [ ] **M9-9b** 在 ② canvas 摆视角(拖动/捏合)→ 记点 → 计数 +1,toast「📍 关键点 n」
- [ ] **M9-9c** 记 ≥2 点后「▶ 预览 / 🎬 录运镜 / 🗑 清空」解锁
- [ ] **M9-9d** ▶ 预览 → 相机平滑依次走过所有关键点(每段 3s,Catmull-Rom 曲线过点不抖)
- [ ] **M9-9e** 播完后停在最后一点,等「无操作恢复时长」后自动旋转正常恢复
- [ ] **M9-9f** 🎬 录运镜 → 自动开始录屏 → 播放路径 → 自动停止保存;回放视频运镜平滑、带水印+timer
- [ ] **M9-9g** 切场景 → 路径自动清空(计数回 0,按钮回 disabled)
- [ ] **M9-9h** 切相机模式(环绕↔室内)后记点被拒,alert 提示先清空
- [ ] **M9-9i** 🗑 清空 → toast「运镜路径已清空」
- [ ] **M9-9j** adb 桥:`kf-add / kf-play / kf-rec / kf-clear` 可用

## adb 快速验证序列

```bash
# 装新 APK
cd client && ./gradlew assembleDebug && adb install -r app/build/outputs/apk/debug/app-debug.apk
# GIF:进场景 → 录 GIF → 刷列表
adb shell am start -n com.roam.app/.MainActivity --es auto guitar
sleep 5
adb shell am broadcast -a com.roam.app.AUTO --es cmd gif
sleep 6
adb shell am broadcast -a com.roam.app.AUTO --es cmd list
# 运镜:记 2 点(中间拖一下视角更直观)→ 录运镜
adb shell am broadcast -a com.roam.app.AUTO --es cmd kf-add
adb shell input swipe 540 800 200 700 300
adb shell am broadcast -a com.roam.app.AUTO --es cmd kf-add
adb shell am broadcast -a com.roam.app.AUTO --es cmd kf-rec
sleep 8
adb shell am broadcast -a com.roam.app.AUTO --es cmd list
```
