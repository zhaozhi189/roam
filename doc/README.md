## 项目状态

- **阶段**:MVP 端到端验证通过(2026-05-16)→ M3-M8 全过(2026-06-12,自扫管线闭环)→ Phase 2 进行中(M9:运镜/GIF/标注已实现待真机验)

- **类型**:个人周末项目;**本地 Android 单机(WebView 套壳)+ 微信视频/二维码分享**(ADR-004/005,不再是 Web SaaS 路线)

## 一句话

Roam(中文「即境」)把"用手机扫一个物件/空间,在手机里走进去、录成视频发微信"做成**一个人就能跑通的本地工具链**,核心技术栈是 3D Gaussian Splatting + PlayCanvas + Brush 自扫训练,**不依赖大模型、不依赖云**。
