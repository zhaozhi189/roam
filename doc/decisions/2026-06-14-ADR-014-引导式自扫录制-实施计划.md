# ADR-014 引导式自扫录制 · 实施计划

> **给执行者:** 本计划按任务逐个实施。每个任务自包含、可独立验证、结束即 commit。
> **验证方式(重要):** 项目 CLAUDE.md 明确「不写测试代码,zhi 一人手动测」。本计划**不用 TDD**,改用项目既有验证链路:`./gradlew assembleDebug` + `adb install` + 自动化测试桥 `runAuto` cmd + `adb exec-out screencap` 截屏 + 真机肉眼。步骤用 checkbox(`- [ ]`)跟踪。

**Goal:** 在 Roam App 内加一个「引导式自扫录制」功能——后摄全屏预览 + 脚本分段引导(准备→水平绕→抬头→低头→闭环)+ 陀螺仪辅助,录成视频存相册并提示传 Mac 跑 `scan-train.sh scene`,把房间自扫的采集质量从「看运气」变「照着拍」。

**Architecture:** 纯前端功能,全部改动落在 `client/app/src/main/assets/index.html`(Web UI)。复用 AR-lite 已验证的 getUserMedia 后摄链路 + DOM 移 body 规避 stacking context 技巧;录制用标准 `MediaRecorder`(webm);引导用一个时间驱动的状态机 + 分段脚本数组;陀螺仪用 `DeviceOrientationEvent`(俯仰判覆盖、alpha 差分判角速度),拿不到则自动降级纯脚本式。落地复用 `RoamBridge.saveVideoBase64` + `arrayBufferToBase64`,**RoamBridge.kt 零改动**(相机权限 ADR-012 已就位)。

**Tech Stack:** HTML/CSS/JS(无框架,原生)、getUserMedia、MediaRecorder(webm/vp8)、DeviceOrientationEvent、PlayCanvas(仅借用现有沉浸全屏)、RoamBridge JsInterface(已有)。

**关联:** [ADR-014](ADR-014-app内引导式自扫录制.md)、[ADR-012 AR-lite getUserMedia](ADR-012-无ARCore设备的AR降级方案-AR-lite-VR.md)、`scripts/scan-train.sh`

```js
function scanRecTick() {
```

- [ ] **Step 2: 用真实 scanRecFinish 替换占位(停录 → 保存 → 提示)**

```js
async function scanRecFinish() {
  const st = scanRecState;
  if (st.timer) { clearInterval(st.timer); st.timer = null; }
  // 停录并等最后一块
  if (st.recorder && st.recorder.state !== 'inactive') {
    await new Promise((res) => { st.recorder.onstop = res; st.recorder.stop(); });
  }
  try {
    const blob = new Blob(st.chunks, { type: 'video/webm' });
    const buf = await blob.arrayBuffer();
    const b64 = arrayBufferToBase64(buf);
    const ts = new Date().toISOString().replace(/[-:T]/g, '').slice(0, 14); // yyyyMMddHHmmss
    const filename = 'roam-scan-' + ts + '.webm';
    const path = (window.RoamBridge && RoamBridge.saveVideoBase64) ? RoamBridge.saveVideoBase64(filename, b64) : '';
    const sizeMB = (buf.byteLength / 1048576).toFixed(1);
    if (window.RoamBridge && RoamBridge.toast) {
      RoamBridge.toast('已存 ' + filename + ' (' + sizeMB + 'MB) · 传 Mac 跑 scan-train.sh <文件> scene');
    }
    console.log('[scan-rec] saved', path);
  } catch (e) {
    console.error('[scan-rec] save failed', e);
    if (window.RoamBridge && RoamBridge.toast) RoamBridge.toast('保存失败: ' + ((e && e.message) || e));
  }
  exitScanRec();
}
```

**Files:**

- [ ] **Step 1: 加陀螺仪监听器(enterScanRec 内,起 stream 后)**

在 enterScanRec 里 `scanRecState.recorder.start();` 之后插入:

```js
    // 陀螺仪辅助(Android WebView 不需 requestPermission;3s 内没事件则判不可用降级)
    scanRecState.orient.available = false;
    scanRecState.orient.lastAlpha = null;
    scanRecOrientHandler = (ev) => {
      const o = scanRecState.orient;
      o.available = true;
      o.beta = (ev.beta == null) ? o.beta : ev.beta;  // 俯仰 -180~180,水平约 90(竖握)
      // alpha 差分估角速度(deg/s)
      const now = performance.now();
      if (o.lastAlpha != null && ev.alpha != null) {
        let d = Math.abs(ev.alpha - o.lastAlpha); if (d > 180) d = 360 - d;
        const dt = (now - o.lastT) / 1000;
        if (dt > 0) o.speedWarn = (d / dt) > 90;  // >90°/s 算太快
      }
      o.lastAlpha = ev.alpha; o.lastT = now;
    };
    window.addEventListener('deviceorientation', scanRecOrientHandler);
    setTimeout(() => {
```

```js
  // 陀螺仪反馈:角速度警告 + 俯仰覆盖打勾
```
